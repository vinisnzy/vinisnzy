# 💫 Sobre mim

Desenvolvedor Backend focado em **APIs REST limpas, escaláveis e bem testadas**.
Base principal em **Java + Spring Boot**, atuando também com **Node.js/NestJS**, **PostgreSQL**, **Prisma** e **RabbitMQ** em sistemas de produção.

- 🔭 APIs de CRM com arquitetura modular, multi-tenancy e integração de mensageria/WhatsApp
- 🧪 **TDD** como padrão — código de produção nasce de teste que falhou primeiro
- 🏗️ Clean Architecture e SOLID Pattern
- 🚀 CI/CD e ambientes conteinerizados com Docker

### 🤝 Colaboração
Backend e APIs com **Spring Boot** ou **NestJS**, **PostgreSQL** e **Docker** — foco em desempenho, segurança e escalabilidade.
